# **App Name**: StyleSavvy

## Core Features:

- Dynamic Product Catalog: Display a dynamic gallery of clothing products on the home page, optimized for fast loading and mobile responsiveness.
- Product Detail & AI Styling Tool: Show detailed product information for selected items, alongside an AI tool that dynamically suggests complementary pieces from the `sugerencias_ids` array to 'Complete your look'.
- Persistent Shopping Cart: Enable users to add, remove, and update quantities of products in a persistent shopping cart.
- Secure Checkout & Payment Gateway Integration: Integrate with a chosen payment gateway (Mercado Pago or Wompi) to securely process payments and update order status via webhooks.
- Product & Order Management Backend: Implement a RESTful API with endpoints for retrieving and adding products, and managing order creation and status updates in the MongoDB database.
- User Order History: Allow users to view their past successful purchases and corresponding order details.

## Style Guidelines:

- Primary color: Muted indigo (`#51628F`) to convey a sense of modern sophistication and depth, fitting a minimalist aesthetic.
- Background color: Very light blue-gray (`#EEF0F3`) for a clean, airy, and minimalist canvas, ensuring high readability and a pleasant viewing experience on all devices.
- Accent color: Bright azure (`#52B9DE`) to provide a refreshing contrast for interactive elements, calls to action, and highlighting important information, without overpowering the minimalist design.
- Headline and Body font: 'Inter' (sans-serif) for its modern, clean, and objective aesthetic, ensuring excellent readability across various screen sizes while maintaining a minimalist feel.
- Utilize minimalist line icons for clarity and to maintain the clean aesthetic. Icons should be easily understandable and support quick navigation.
- Employ a mobile-first design strategy with generous white space, clean grid layouts for product display, and clear hierarchy for information. Prioritize content with an intuitive, uncluttered user flow.
- Implement subtle, swift animations for user interactions and transitions between pages, ensuring a fluid experience without detracting from fast image loading and overall performance.
